# odin-recipes

I added three recipes from Japanese cuisine, shortest being The Easiest Nigiri recipe, and the longest -- Tonkotsu Ramen recipe.

I practiced the use of unordered and ordered lists, and relative and absolute links. You can access each of the three recipes from the main index.html page, and return to index.html from any of the recipe pages via the "Home" link. Also I practiced using Git and writing comprehensible commit messages.

This is my first project on The Odin Project.
